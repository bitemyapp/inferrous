# Device indexing and lifetime contract

The optimized build uses cuda-oxide's `--unchecked-indexing` for this crate's device code only. Host request and model validation remain checked. Set `CLEAN_BOUNDS_CHECKS=1` when invoking `tools/cuda.sh` for the checked variant. New kernels or graph changes must re-establish this contract; do not treat an arbitrary slice as admissible merely because it is a Rust slice.

There is one model constructor: `Model::load`. Tensor storage, matrix dimensions and layers are crate-private, so callers cannot replace validated shapes before `GpuModel::new`. The loader admits only the fixed Qwen3 dimensions, exact tensor sizes, finite floating-point data, positive scales and INT8 weights in [-127,127]. Every legacy `GpuModel` generation call validates nonempty input, positive output count, checked-add context length <= 4096 and vocabulary IDs < 151936. The paged engine extends the admitted context under the additional contract below. No public API accepts arbitrary device buffers or launches the private kernels.

|---|---|
| embedding | Output has `rows*4096` elements; each admitted ID selects one of 151936 complete weight rows. Excess launch threads return. |
| norm | One 256-thread block per complete gain-width row. Width is 128 or 4096 in the model; fixtures also test 12288. Each thread loads its coordinates `t + 256*i` in 4096-wide chunks (sixteen register slots, guarded below width) before summing them in the original ascending order. Rows of at most 4096 keep values and gains in registers for the output; wider rows reread both. All 256 shared slots are initialized before reduction. |
| Fused norm/quantize | Exactly 1024 threads each own four coordinates of a 4096-wide row, loading those coordinates' gains before the reduction. They populate 4096 distinct shared values; the first 256 threads reproduce the original sixteen-term partial sums. The original sum tree is reproduced across shared slots and warp shuffles; only warp zero uses the sum collectives. The maximum uses all 32 full warps and 32 shared partial maxima. Barriers protect sum consumption before shared reuse and max publication before quantization. The norm, INT8 and scale outputs are distinct. |
| quantize | One 1024-thread block per complete 4096/12288-wide row; Q buffer exactly matches input length and scale has one element per row. |
| MLP maximum / known-maximum quantization | Hidden norm resets one u32 maximum per row to the positive floor bits. For one 12288-element decode row, SwiGLU warps are complete and publish unsigned absolute-float maxima through device-scope atomic max; NaN bit patterns are ignored. Only atomic accesses occur during that kernel. Stream order separates ordinary reset and later reads. The quantizer writes each INT8 coordinate once; only the first coordinate of each row writes its scale. Prefill retains its original quantizer. |
| DP4A linear | One complete warp per output; widths are multiples of 128, four-byte packed loads aligned; row/channel derive from the bounded output index. |
| Fused DP4A residual | Each complete warp owns one output coordinate. Lane zero writes the rounded projection and then the rounded sum into separate buffers, reading the matching coordinate from a third, read-only residual buffer. Runtime admits one full decode row; integer/scaling order and both BF16 boundaries match the separate kernels. |
| Fused gate/up activation | Exactly 256 threads (eight complete warps) per CTA. Each warp owns one matching gate/up coordinate, sharing aligned activation words between two independent INT32 dots. Lane zero writes the two BF16 projections and original rounded activation into three distinct allocations. Each warp leader initializes one of eight shared maximum slots, including inactive tail warps. A block barrier precedes the first complete warp reducing those eight values and publishing one device-scope atomic maximum; NaNs are ignored. The earlier norm reset and later quantizer are stream ordered. Runtime supplies one full decode row; partial-channel tests retain full warps/barriers. |
| Grouped DP4A projections | Each complete warp selects one sibling matrix by its output-channel index. Sibling inputs share the same activation rows/width; each weight/scale/output has its own validated shape and distinct output allocation. The selected branch is uniform within a warp. Dot products and warp reductions match the single-projection kernel; only lane zero writes. Runtime selects grouped kernels only for decode. |
| MMA linear | K is a multiple of 32. Missing rows/channels in each 16x8 tile are zero-filled before any load; all 32 lanes participate. Each lane owns four distinct output fragments, guarded at tile edges. |
| Split-K MMA linear | Exactly 256 threads split K into eight multiples of 32. Each warp writes 128 distinct shared INT32 cells; a barrier precedes the first 128 threads reducing their cells across warps. Every admitted output has one writer and the absolute sum bound prevents overflow. Runtime uses this for 2–31 rows. |
| Tiled MMA linear | Exactly 256 threads partition a 32x64 output tile. K is a multiple of 128. Padded shared rows have 36 words; the largest accessed A/B indices are 1147/2299, within 1152/2304 slots. Global tile tails are zero filled. Warp matrix loads receive 32 aligned row addresses: A uses rows wr+lane%16 and K offsets j+4*(lane/16); B uses rows wc+8*(lane/16)+lane%8 and K offsets j+4*((lane/8)%2). These deliver exactly the original packed fragments. Every warp owns a distinct 16x16 subtile, and all threads pass the load/read/reuse barriers. |
| Large MMA linear | Exactly 256 threads partition a 64x128 output tile; eight warps own 32x32 regions. Immutable TMA maps describe complete row-major A/B allocations with K divisible by 128. The 128-byte swizzle permutes four-word chunks within each shared row; 1024-byte alignment fixes its base offset to zero. All accesses fit 2048/4096 A/B words. Thread zero initializes a one-arrival barrier and fences it to the async proxy. Each K stage registers 24576 bytes and issues two CTA-local bulk copies. Every thread waits for that phase before matrix loads; a block barrier follows the final read before reuse. Parity alternates once per stage and invalidation follows the final barrier. Global tails are zero filled by the tensor map; output tails remain guarded. |
| Fused head norm/RoPE | Exactly 128 threads stage one complete head. Warp zero reproduces the original norm sum tree, including the former zero-filled upper 128 slots. Barriers protect sum consumption before staging the BF16 norm values; the first 64 threads then write distinct in-place coordinate pairs. Table positions and head gains obey the same bounds as separate norm/RoPE. |
| RoPE | Input/output have `rows*heads*128` elements, heads 32 or 8. Split coordinate pairs partition the output; request position plus row remains below the 4096-row table. |
| Combined Q/K preparation | A 128-thread block owns one of 40 heads per token: 32 Q or eight K. It reproduces fused head norm/RoPE, loading its gain, position and (first 64 threads only) RoPE pair before the reduction; K blocks also write both rotated K halves and the matching V coordinates into their unique admitted cache positions. Q/K source coordinates are staged before in-place writes. Q, K, V, gains, table and caches are distinct allocations except for explicitly read-only gains in operator tests. |
| KV append | K and V contain `rows*1024` elements. K writes `coordinate*4096 + position + row`, V writes `(position+row)*1024 + coordinate`; the admitted context bounds both 4096-token caches. Each coordinate is appended once. |
| attention | One 128-thread block per query/head. GQA maps 32 Q heads to eight KV heads. Key indices are below `position+row+1 <= 4096`; coordinates below 128. K is coordinate-major, V is token-major. Shared scores have 4096 entries and reductions 128. Barriers protect every cross-thread phase. |
| Grouped prefill attention | Exactly 512 threads own four adjacent Q heads, each with independent 128-thread reductions and a 512-element score region. Host dispatch requires 32 or more rows and at most eight 64-key tiles, bounding every score index. Each GQA group shares one KV head and one staging tile; 512 threads each copy two distinct fragments. Output ownership and every per-head reduction/order match original attention. |
| Split attention | Independent 64-key tiles write unique scores at query*4096+key. Whole blocks return for invisible tiles before any barrier. The following kernel reads only the fully written visible prefix, with stream ordering between launches; it reproduces the original softmax/PV order. Scratch contains rows*32*4096 f32 elements. |
| Split PV attention | Softmax reads/writes only its uniquely owned query/key scores and retains the original reduction tree. A later 32-thread block owns 32 coordinates, four blocks per query/head. Each of two staging slots contains 64x32 BF16 values and 64 probabilities; next-tile copies target the slot no longer being read. Completion/barriers precede consumption and reuse. Ascending key order is unchanged. |
| residual / SiLU | All source/destination lengths match the fixed graph; launch tails return. |
| Greedy selection | Exactly 1024 threads scan disjoint vocabulary indices, then reduce 32 full-warp results using 96 shared u32 slots. The lexicographic comparator preserves lowest-index ties including signed zero. A separately OR-reduced flag rejects any nonfinite input with a sentinel; the host validates it before using the token. One thread writes the single result slot. |
| output head | Nonempty input has complete 4096-wide rows. One complete warp per vocabulary output indexes a complete 4096-wide head row. The private host packer maps each 256-value chunk to 96 u32 words and one exception offset. Thirty-two lanes each load three word planes for eight successive terms; the maximum plane index is 95. A reserved exponent code indexes at most 256 original BF16 exceptions per chunk, with exact u16 reconstruction. Word and exception offsets fit u32; the packer divides before multiplying. Packed allocations live with the model and outlive captured graphs. |

INT8 products cannot overflow the INT32 accumulator: even the full 12288-wide dot is bounded by 198193152. Local MMA array indices are bounded by four/two. All shape/address products fit 32-bit unsigned arithmetic at admitted sizes; host admission also checks the context addition for overflow.

The model owns an execution pool, serialized by a mutex. Its eight decode graphs capture only kernels, using stable weights, module, KV, decode scratch and a two-u32 control allocation. Control contains the next token ID and absolute position; the host admits both before copying, and all position kernels read control[1]. Graph bounds cover 64/128/192/256/512/1024/2048/4096 visible tokens; whole QK blocks outside the current causal prefix return without touching scores. Prefill runs eagerly into reusable scratch sized to the current prompt.

Every request overwrites its entire visible KV prefix before reading it. Stale future entries are never used in arithmetic. Stream order protects all producers, consumers and subsequent reuse. Residual sources and their outputs are distinct. In-place Q/K preparation stages each complete head before writing its coordinates. Each synchronized logit read completes the step before the next control update. Entry synchronization also handles an earlier failed eager run. The execution pool drops graphs before scratch; the model drops its pool before weights/module. Graph destruction synchronizes the owning stream. Capture guards end invalidated or unwound captures and release any returned source graph. Raw graph operations bind the owning context; the mutex excludes simultaneous launches, buffer changes and trace requests. Kernel writes remain disjoint by coordinate, warp or block.

The smaller prefill staging arrays explicitly require 16-byte alignment. Async copies target distinct aligned fragments; zero-fill tails use a valid dummy global address. Each issuing thread completes its copies before a block barrier makes the bytes visible to other warps. A second barrier precedes staging reuse.

Attention also stages aligned 64x128 BF16 tiles in a distinct 16-KiB shared allocation. K is staged coordinate-major and V token-major. Tile bases are multiples of 64, so even the last full staging tile remains within the 4096-token cache capacity. Only the visible prefix contributes to scores or output. Copy completion and block barriers precede reads; all readers finish before reuse. The query, scores and reductions have separate shared allocations.

Q/K/V and gate/up share read-only quantized activation bytes and scales. Their common producer precedes every projection, and no write to that scratch is queued until all sibling reads are queued on the same stream.

Validation requires checked-versus-optimized full vocabulary hashes, independent operator fixtures (including partial MMA tiles and position 4095), and Compute Sanitizer checks. These validate the admitted domain; they do not make unchecked kernels safe for arbitrary future dimensions. Numerical accuracy across external engines is a separate issue, documented in the discrepancy notes.

The large prefill tensor maps are driver-encoded into aligned 128-byte host descriptors and uploaded to CUDA allocations (at least 256-byte aligned). The source tensor pointer is 128-byte aligned, row stride is divisible by 128, and the map dimensions exactly match the source allocation. Maps are immutable; stream order completes their upload before use. The model owns weight maps and sources; each prefill workspace owns its activation maps and sources. Those objects outlive every queued launch, and prefill scratch replacement occurs only after entry synchronization. Map allocations are created after ordinary tensor allocations. The PTX destination uses `.shared::cta`, matching the private staging/barrier addresses and avoiding an unnecessary cluster fallback on SM120. No extra copy of INT8 weights is stored.

Result transfers use two persistent pinned host slots owned by the serialized execution pool. Step parity chooses the destination; the CPU hashes only the other slot, whose preceding transfer has completed. Both logit/selection copies are queued on the compute stream before one synchronization, and subsequent scratch/control reuse follows that fence. No host read, mutation, resize or free of the destination is allowed before completion. Entry synchronization handles an earlier failed submit; `Readback::drop` synchronizes before its pinned fields can drop, including when the second enqueue fails. Slot allocation occurs at model load; every step still transfers every logit and the selected token.

Decode graphs use programmatic edges. After capture, `graph.rs` replaces every kernel-to-kernel edge with a `CU_GRAPH_DEPENDENCY_TYPE_PROGRAMMATIC` edge from the programmatic port, so a kernel may launch once every CTA of its predecessor has executed `griddepcontrol.launch_dependents` or exited. Every kernel that can appear in a decode graph executes `griddepcontrol.wait`, with a compiler memory clobber, in every real CTA before reading or writing any buffer that another kernel produces, consumes or reuses, and only then admits its successor. The wait returns after every prerequisite grid has completed and its memory operations are visible, so each real CTA observes the order it had under ordinary edges. A grid cannot complete before its real CTAs pass their wait, so completion stays transitive along the chain and lookahead is one kernel. Work before the wait reads only kernel parameters, immutable weights and the read-only control record, and issues L2 prefetch hints. Graph launches, transfers and eager launches keep full stream order; for eager launches both instructions are no-ops. `CLEAN_PDL=0` restores ordinary edges.

Decode L2 prefetch hints return no data and create no ordering; they cannot change any value, hash or token. `CLEAN_PREFETCH=0` disables them and restores the earlier launch shapes.

- Attention, split-attention softmax and decode O quantization append sixteen CTAs. Blocks at or beyond the real block count (query heads, score rows or quantized rows) return before any barrier or shared-memory access. Thread zero issues `cp.async.bulk.prefetch.L2.global` over one 128-byte-aligned share of an O weight range clamped to the allocation, in pieces of at most 16 KiB whose sizes are multiples of 16, from a base aligned to at least 256 bytes. These blocks read and write no buffer and therefore need not wait.
- Before waiting, each projection or head warp issues `prefetch.global.L2` for 128-byte lines of its own weight row, at offsets `lane*128 + 4096*i` below `min(budget, row bytes)`. The row derives from the same bounded output index as the warp's dot product; tail warps issue nothing.
- With a nonzero budget, QKV threads also issue one line each over the visible K prefix (1024 coordinate rows, line start below `position + 1`) and the visible V prefix (line start below `(position + 1) * 1024`, clamped to the cache length).

Native integer warp reductions require all 32 lanes named in the mask to participate. DP4A tail conditions select complete warps; producer-max and final block-max cohorts are complete first warps. Unsigned sums give the same signed INT32 dot modulo 2^32, and admitted final sums fit INT32. Unsigned max inputs are nonnegative float encodings with NaNs excluded and positive scale floors. Floating-point sums retain their original trees. Native nearest-even conversion follows the original clamp and returns the same low INT8 byte, tested at ties, adjacent FP32 values, all BF16 encodings and a broad FP32 bit sample.

## Paged runtime

`BatchEngine` additionally admits contexts through 32,768, bounded by the validated bundle's RoPE table, and at most 64 simultaneous sequences. A row chunk contains at most 1024 token rows and at least one row for every unfinished sequence. Each row carries a validated sequence slot and absolute token position. The page table has `max_batch * ceil(max_context / 64)` entries; the runtime fills every admitted sequence's reserved entries with page IDs from its own bounded pool. Kernels only read initialized causal positions or the physical page containing them. Invalid unused entries never participate in addressing. Every sequence owns private pages for the range it will write; shared pages contain only immutable complete initialized prefixes.

Paged Q/K preparation uses the original per-head arithmetic and writes unique `(page, coordinate, within-page token)` K cells and `(page, within-page token, coordinate)` V cells. Paged scores preserve the original ordered QK dot, and softmax preserves the 128-thread reduction tree. Paged values accumulate in increasing logical token order. Score scratch is `rows * 32 * stride`, where `stride` is the next power of two covering every visible key prefix, capped at 32,768. All query/key reads are causally bounded. Indexed output heads use only rows admitted as final rows of current sequence prefixes, and each output has a distinct complete vocabulary/logit/selection region.

Grouped paged scores use 128 threads per `(row, KV head, 64-key tile)` and stage four adjacent Q heads in 512 FP32 shared entries. Those heads share exactly one of eight KV heads and the same sequence/page mapping. Threads 0–63 own distinct causal keys and four independent sums; each head still traverses coordinates 0–127 in order. Grouped paged PV uses one 32-thread block per `(row, KV head, 32-coordinate slice)`. It stages a shared 64×32 BF16 value tile and four distinct probability rows in each of two slots. All async copies complete before reads; barriers separate slot reuse. Each thread publishes four distinct output coordinates after preserving increasing logical key order and the original BF16 rounding. The same page, causal-prefix and score-stride bounds apply to both variants. Dispatch keeps the original kernels available, and avoids grouped PV at small row counts where fewer blocks reduce occupancy.

Grouped packed heads launch complete 256-thread blocks, with one warp per `(vocabulary row, group of four or eight output rows)`. Const specialization shares weight reconstruction while each output retains a separate FP32 accumulator and the original shuffle tree. Admission validates all indexed source rows. A partial output group pads input selection with the last admitted row, and checks each member before publishing; it never reads an absent source index or writes a padded output. The vocabulary bound is checked uniformly by each warp before any output work. Distinct warps own disjoint output cells. The operator experiment compares every full vocabulary result at every batch size 1–64, including reversed source-row selection; model tests and paired probes exercise ragged retirement and both group widths.

A session borrows its engine, which owns the device page pool and model weights. Mutable session references exclude concurrent updates or release during generation. The execution mutex serializes all GPU work; each forward step completes before written lengths advance, and both successful and failed calls fence the stream before returning caller-owned leases. Persistent step storage owns transient buffers and fences on drop, including partial failures. An execution error poisons the engine so partially written state cannot be reused. `restart` rejects any shared page and invalidates only initialized length after a fence; recomputation detaches existing shared state before reserving private storage. Capacity and admission errors occur before kernels and do not poison the engine. Short-model tests establish exact compatibility with the original path. Full-model ragged 8K/16K/near-32K cached/recomputed comparisons pass in both release and checked release; Compute Sanitizer reports zero errors for paged operators and a four-sequence full-model CLI run, and Racecheck reports zero hazards for the paged operators. The complete benchmark shape matrix remains separate.

Paged decode graphs drop before the caches they capture, and the enclosing engine drops its runtime before model weights or module handles. A per-call unwind guard also synchronizes the stream if host code panics; normal completion disarms it only after a successful fence. This prevents caller-owned session pages from being released while an unwound call still has queued users. The poisoned execution mutex prevents further work after a panic. Configuration validation bounds each per-layer KV allocation to the 32-bit device index range.

The model's validated RoPE capacity is private, exposed only through `Model::max_context()`. An application cannot increase the admission bound without loading and validating a corresponding RoPE table. Engine configuration is validated on construction and exposed read-only afterward.

The adaptive row budget bounds each sequence's possible next position by `min(token_length, written + prefill_chunk)` before choosing the chunk size. Its score stride therefore bounds the actual stride after packing. The scheduler limits rows to `score_scratch_bytes / (32 * stride * sizeof(f32))`; construction requires enough budget for at least one query per admitted sequence even at maximum context. This preserves nonempty per-sequence quotas and bounds the allocation product. A replaced step is dropped before its replacement is allocated. Indexed heads interleave `(vocabulary row, batch row)` in their launch mapping and store to `(batch row, vocabulary row)`; the mapping is bijective over the admitted output matrix and each warp retains the original dot order.
